## 🛠️ How to Compile & Run the Code

### Method 1: Command Line / Terminal

Navigate to any topic directory and compile the Java file:

```bash
# Navigate to a module
cd Basics

# Compile the Java file
javac BasicsDemo.java

# Run the compiled bytecode
java BasicsDemo
```

### Method 2: VS Code / IntelliJ IDEA / Eclipse
1. Open this repository folder in your IDE.
2. Open any `.java` file in the topic directories.
3. Click **Run** or press `Shift + F10` (IntelliJ) / `Ctrl + F5` (VS Code).
